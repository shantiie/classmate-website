CLASSMATE WEBSITE - SETUP

1. Extract ClassMate-Website.zip.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in your browser, or install the Live Server extension and choose "Open with Live Server".
4. Sign in with any name, course, section, and password (4+ characters).

FILES
- index.html: website structure
- styles.css: design and responsive layout
- app.js: login demo, timetable, event board, quiz bank and custom quizzes

FEATURES
- Student demo login
- Personalized timetable and next-class countdown
- Add/remove personal announcements
- Quiz Arena: Chemistry, E-Chemistry Lecture, Biology, Calculus (25 questions each)
- Create a one-question custom quiz
- Browser notification permission button

IMPORTANT
This is a front-end learning prototype. User data is stored in localStorage on the current browser/device. Login is not secure authentication. Announcements are personal, not shared campus-wide. Notifications depend on browser permissions and may require the page to remain open. A real school-wide deployment needs a secure backend and database.
